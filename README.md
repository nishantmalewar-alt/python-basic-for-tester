# Python Basics for Testers 🐍

### 📖 Overview
This repository contains basic Python logic and practice programs specifically for testers to build strong automation fundamentals.

### 🛠️ Topics Covered
* **Variables & Data Types:** Basic arithmetic operations and assignments.
* **Control Flow:** Even/Odd check, If-Else logic, and Loops.
* **Logical Programs:** Squares of numbers, Palindrome check, and sequence printing.

### 📂 File Structure
* **`day2_loops_functions.py`**: Practice programs on loops (for/while) and basic functions.
* **`day3_practice.py`**: Intermediate logic building tasks and practice exercises.
* **`day5_practice.py`**: Advanced logic including Squares of numbers and Palindrome check.
* **`Check_Odd_Even.py`**: Basic conditional logic to identify odd and even numbers.
* **`Print_1_to_10.py`**: Simple loop practice to print numbers in a sequence.

### 🏃 How to Run
Make sure you have Python installed. Run any file using:
```bash
python <filename>.py

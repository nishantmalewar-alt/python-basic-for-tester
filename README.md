# Python Basics for Testers 🐍

### 📖 Overview
Day‑wise Python practice: variables, loops, functions, lists, strings, small problems for QA/SDET preparation.

### 📂 File Structure & Lessons
* **day1_basics.py**: Practice on input, print, and basic loops.
* **day2_loops_functions.py**: Exercises covering lists and function definitions.
* **day3_practice.py**: Focused on loop logic and string manipulations.
* **day5_practice.py**: Logical programs like squares, palindrome, and vowels.
* **Check_Odd_Even.py**: Basic conditional logic practice.

### 🏃 How to Run
Make sure you have Python installed. Run any file using:
```bash
python <filename>.py
